# Лабораторная работа №7

Работа со строками, регулярными выражениями и форматированием вывода в Python.

## Содержание

| Файл | Задание |
|------|---------|
| `t1.py` | Подсчёт количества слов в тексте |
| `t2.py` | Проверка строки на палиндром |
| `t3.py` | Шифр Цезаря для русского алфавита (шифрование и дешифрование) |
| `t4.py` | Валидация email, телефона и URL с помощью регулярных выражений |
| `t5.py` | Форматированный вывод таблицы студентов и среднего балла |
| `t6.py` | Поиск самого длинного слова в тексте |

## Описание заданий

### t1.py — Подсчёт слов
Пользователь вводит текст, программа считает количество слов. Слова находятся с помощью регулярного выражения `\b\w+\b`.

```
Введите текст: Привет мир
Количество слов: 2
```

### t2.py — Палиндром
Строка приводится к нижнему регистру и очищается от всех символов, кроме букв и цифр. Затем проверяется, совпадает ли она со своей перевёрнутой версией.

```
Введите вашу строку: А роза упала на лапу Азора
Ваша строка палиндром.
```

### t3.py — Шифр Цезаря
Функция `cesar_shiefr(text, shift)` сдвигает каждую букву русского алфавита (включая `ё`/`Ё`) на заданное число позиций. Регистр сохраняется, остальные символы остаются без изменений. В конце выполняется дешифрование обратным сдвигом.

```
Впишите число, на которое нужно сдвинуть алфавит: 3
Введите текст для шфирования:
Привет
Оригинал: Привет
Зашифрованный текст: Тулзйх
Привет
```

### t4.py — Валидация данных
Три функции на регулярных выражениях:

- `validate_email(email)` — проверяет формат email;
- `validate_phone(phone)` — проверяет российский номер (`+7` / `7`, с дефисами, пробелами и скобками);
- `validate_url(url)` — проверяет URL с протоколом `http`/`https`.

В конце прогоняется набор тестовых значений с выводом `[OK]` / `[FAIL]`.

```
[OK]   | EMAIL | anna.petrova+work@company.ru
[FAIL] | URL   | ftp://my-site.org
```

### t5.py — Форматированный вывод
Выводит список студентов (имя, возраст, балл) в виде выровненной таблицы и считает средний балл.

```
Имя            Возраст     Балл
-------------------------------
Иван      | 25      | 4.50    |
...
Средний балл              4.63
```

### t6.py — Самое длинное слово
Текст очищается от знаков препинания, после чего с помощью `max(..., key=len)` находится самое длинное слово.

```
Введите текст: Программирование — это интересно!
Самое длинное слово в тексте: Программирование
```

## Требования

- Python 3.8+
- Дополнительные библиотеки не нужны (используется только стандартный модуль `re`)

## Запуск

```bash
python t1.py
python t2.py
python t3.py
python t4.py
python t5.py
python t6.py
```

## Используемые приёмы

- Модуль `re`: `findall`, `sub`, `match`
- Строковые методы: `strip`, `lower`, `split`, `index`
- Срезы и обратный порядок `[::-1]`
- f-строки с выравниванием (`<`, `>`) и точностью (`.2f`)
- Работа с Unicode-диапазонами русского алфавита
